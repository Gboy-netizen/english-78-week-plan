# 每天一点英语 · v3

每天60分钟，六天训练、一天复盘。先完成三天诊断，再从下一天开始自己的78周；目标 IELTS General 总分6.5、单项6.0，可调整。

## 使用

双击 `start-learning.cmd`（需要Python），访问 `http://localhost:4173/`。也可运行 `python tools/start_site.py`。

直接打开 `index.html` 可使用本地文字与真人音频；若浏览器限制录音或存储，请使用本地HTTP或发布后的HTTPS。**文件网址、localhost、公共网址各自保存记录，换入口需用完整学习包迁移。**

1. 三天诊断：听说、阅读/词块/句法、写作/情境口语。困难时从基础恢复开始，写说反馈可以稍后补。
2. 今日课堂：提取10分钟、输入20分钟、输出15分钟、反馈10分钟、保存5分钟。专项读写整小时替换普通任务。
3. 先独立保存首答、原稿和录音，再看解析或求助AI；反馈保存2–3个动作，默认三天后复测。
4. 每周新材料检查，结合延迟提取安排两个补强课时；不追补、不加每日时间。
5. “资料与备份”导出完整ZIP学习包，保存文字、原始录音与关联。纯文字JSON不包含录音。课程安装包可下载完整版或六个阶段包；阶段包只配备对应阶段真人录音，学习记录另导出。

旧版页面在 `legacy/index.html`，原浏览器数据键和录音数据库不删除。新版会迁移同一来源网址的旧记录；也可导入旧JSON和含录音的旧学习包。没有在新入口看到旧数据时，回原入口导出再迁移，不能把不同网址当作自动同步。

## 课程与材料

- 78个周单元、546天任务，六个阶段。156份核心/迁移阅读；后28周增加预约、租房、报销、公共服务等原创迁移案例，后期主阅读合并观点与应用文本。
- 前12周重新选取24节真人短句课，含意思题、关键词、中文支持和换情境任务。教学改写例句与原始音频转写分别标明，逐步减少支持。
- 156份本地真人朗读MP3，附转写、分段时间、原始语料ID、作者/朗读者、许可和SHA-256。它们是文学朗读，**不是按CEFR认证的分级对话，更不是IELTS试卷**；基础阶段仍需结合分级真人对话、提示和较易阅读。
- ELLLO按A1/A2/B1/B2提供自然对话原站和流播放入口。只记录网址，不打包其受版权保护的录音或全文。原站访问受网络条件影响；不能沿用本地朗读题目给另一份对话评分。
- 独立真人目标音、视频来源、A/B回放、自评和问题音复练。没有真人例词配音时明确做文本练习，不默认使用TTS。
- 写作、口语、词块和句法贯穿每周；外部ChatGPT/豆包通过复制提示词、粘回结构化JSON使用，无API、账号后端或自动机器发音评分。

**结构与解码审计不等于教学质量认证。** 自编题及候选证据尚未独立教师逐项复核，内容状态与问题报告可见，不能换算雅思band。真人朗读者的口音和媒体人工试听也不由构建自动认证。

## 考试证据

登记合法来源、具体测试编号、是否见过、形式和日期。听读写按材料说明分科连续计时，口语同日独立进行；刷新、暂停、提前结束、时间异常均记录。W56、W68、W76各预留约3小时，替代当天普通课，共约增加6小时。

准备度要求两批不同未见材料、完整四科及评分证据、目标达标、复盘完成，至少一次连续听读写和同日口语。听读没有适用官方换算就保留原始分，写说需要可识别人工来源与维度；AI和自评不触发达标。网站不包版权不明的Cambridge试卷，也不保证考试分数。

## 备份与恢复

ZIP包含 `progress.json`、`audio/`、录音对应清单、写作/反馈、版本与文件校验值。原始产出关联的录音不会被后续录制修改。任何音频读取失败会阻止“完整导出成功”；缺文件、损坏、无效版本和断裂关联会阻止恢复。

恢复先校验、下载当前完整备份，再用IndexedDB事务切换。默认合并并保留冲突，替换模式保留旧完整版本，可点击“恢复上次导入前的数据”。录音也支持逐条及批量下载。飞书是手动摘要副本，不能替代原稿和录音备份。

同步脚本校验根目录和 `github-pages-site/` 文件哈希，**不提交、不推送、不部署**。公开发布后需另查实际公共URL、手机、官方入口与飞书跳转。

许可见 `SOURCES.md` 和逐文件音频清单。回滚包保存在 `_backup/`；不发布缓存、回滚包、个人学习包和浏览器数据。
