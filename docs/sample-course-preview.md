# 全量情境课堂

本地预览：<http://localhost:4173/?sample=1&day=1#today>

现在这不是只含两周的样板：入口已经覆盖 W1–W78。链接中的 `sample=1&day=1` 只是默认打开第1周第1天；可以把数字改成任意 `sample=1..78` 和 `day=1..7`，或从课程地图点击任意周进入。

前两周是人工编写得更细的生活场景，主题分别是：

- 第1周：认识新同学。姓名、来处、工作、学习目标、请求重复、社区活动。
- 第2周：安排一天、约定时间。时间表、限制条件、改期邮件、预约和小组安排。

每天固定 60 分钟：10 分钟回想、20 分钟输入、15 分钟主动输出、10 分钟反馈重练、5 分钟保存安排。14 天的输入、示范、错误对照、输出模型和三天后迁移任务全部独立编写；词块每周 25 项，按情境和搭配组织。

课堂遵循“先答后教”：首答阶段不显示原站全文、答案或本站示范。提交后才出现证据和教学说明；查看示范、原站全文或本地备用材料都会留下提示或材料状态。输出先保存原稿和录音，再允许修改稿关联原始产出。自评要求填写证据、两个动作和三天后的新情境复测。

第1、2、5天使用 ELLLO 的短真人对话在线播放。项目只保存来源、片段、题目证据和访问检查，不打包原站录音或全文。2026-10-13 的本机代理访问和 ffmpeg 解码均通过，国内直连、逐项人工试听和未来网络可用性尚未确认。播放器失败时可切换本地真人短句；切换后的练习独立记录，不能假装完成原对话。

W3–W78 使用同样的教学结构，围绕各周已有的阅读、迁移阅读、真人朗读和阶段目标编排 7 天独立任务；任务 ID、词块和复测提示按周生成，不把前两周文本冒充成后续新材料。样板课堂不会自动启动学习周期，浏览课堂也不会记为课程完成。使用中保存的练习、录音、反馈和复测会进入当前本机学习记录；没有学习周期时只能浏览。
