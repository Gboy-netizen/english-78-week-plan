# v3 本地交付与验收记录

日期：2026-10-10。版本：3.0.0。目标：IELTS General 总分6.5、默认单项6.0；免费优先，外部AI，无账号后端。

当前结论：新版课程组织、课堂、反馈、考试证据和备份流程已经实现，能够本地使用；尚不能称为经过独立教师审定的成熟标准化课程。技术验收、链接访问、人工试听和教学质量分别记录。

## 实际验证

- 3.0.1题目泄露整改：核查全部78周当前课程与入学诊断。截图2题的英文词根提示已移除；30道听力题的目标词在自身题干、邻题或标题出现的问题已修正；78个句法面板的规则与正确例句改为提交后显示。题干全量机器检查与浏览器提交/提示路径已加入回归，旧记录保留。此检查不代替教师内容审查；存档旧版页面保持原样。
- 引擎测试：546天预算、起点调整、补强替换、三次长模拟、首答保留、材料来源历史、证据反馈、雅思总分取整、准备度排除与冲突保留通过。
- 本地HTTP浏览器：Playwright 1.63.0配套Chromium，390/768/1440宽度通过主要页面检查。诊断、新周期、首答、模拟设备录音、反馈、重练、发音自评、刷新中断和媒体失败降级通过。
- 数据验证：真实Blob字节与哈希往返；损坏ZIP拒绝；旧格式与旧录音迁移；模拟音频读取失败、存储不足；同ID音频冲突保留双方；恢复回滚；多页面旧版本写入及恢复拒绝。
- 考试验证：单批、重复材料、AI评分、缺人工资格、缺科、未复盘、提示、中断、设备时钟变化、超时均不能制造准备度。连续听读写同时使用同一页面会话的单调时钟与系统时间核对。
- 媒体审计：156份核心音频、1份诊断和46个独立目标音MP3全部完成实际解码检查。47张音素卡中/ɝ/与/ɚ/明确共用样本。
- 完整课程包及六阶段包与当前文件逐项比对通过；文件覆盖和对应阶段录音数量通过。构建一致性通过。
- 11项外链访问抽检：9项能访问。ELLLO A1/A2/B1/B2页面及抽检音频返回200；UBC发音入口返回200。IELTS General样题页读取超时；Rachel页面返回403。这里只检测入口和音频流访问，不代表浏览器播放器已播出或逐项人工试听。
- npm依赖审计零已知漏洞。根目录原版与发布目录覆盖前均有回滚ZIP，个人浏览器数据不随发布同步。

本地详细日志和截图保存在 `_shots/`，包含 `media-validation-v3.json`、`online-media-checks-v3.json` 和三种宽度的页面截图。访问抽检快照同时保存在 `data/resource_checks_v3.json`，构建不会自动把未核验资源改成已核验。

## 尚未通过的外部验收

1. **教师审查与难度校准**：当前独立人工复核单元为0。至少按阶段抽检10%，后期考试题型任务全部复核；修订需更新内容版本。自编训练不作为标准化能力证明。
2. **真人材料质量与口音**：文件可解码不等于已逐项试听。还需核对清晰度、上下文、口音和难度；自然对话覆盖不能只靠文学语料数量替代。
3. **真实设备**：浏览器测试使用模拟麦克风。实际设备的录制、播放、导出恢复，以及真实手机使用尚无本次运行证据。
4. **远端发布**：CI文件已配置，但未运行远端CI；发布目录同步不代表公共HTTPS网站已更新。公开上线后仍需公共URL、手机、官方入口和飞书跳转检查。
5. **考试材料与人工评分**：网站提供登记与证据管理，不内置版权不明的Cambridge试卷，不提供考官资质认证，也不保证任何考试分数。

## 使用与复现

双击根目录 `start-learning.cmd`，或运行 `python tools/start_site.py`，进入 `http://localhost:4173/`。先完成三天诊断，再开始新周期。文件入口与HTTP入口的浏览器记录互不自动同步；有旧记录时使用旧入口导出完整学习包后迁移。

```text
npm ci
npx playwright install chromium
python build_plan.py --check
npm test
python tools/audit_v3.py --decode
python tools/check_release_packages_v3.py
python tools/check_online_media_v3.py
python tools/sync_release_v3.py
```

Windows本地媒体审计需要ffmpeg；CI已配置安装。同步脚本复制并比较公开文件哈希，排除缓存、回滚包、个人学习包和浏览器存储，不执行提交、推送或部署。
