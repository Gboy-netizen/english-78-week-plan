## 用途和边界

这是现有 78 周英语计划的一个小试点，不替代原来的每日课堂。建议先试两周，每周新增 8 张（词汇/搭配、听力理解、口语复述、写作纠错各 2 张），每次 10–15 分钟；把 Anki 复习放在当天课程之后。三天后用新情境复述或改写一次，观察是否能迁移。出现积压或挤占听说读写主练习时，先暂停新增卡片。

Anki 的间隔复习只用于安排回看，不能换算或保证 IELTS 6–6.5，也不能代替限时听读、真实写作批改和口语反馈。当前项目文档的最新口径是 IELTS General 6.5；考试类型和目标仍需你确认。

## 文件

- `anki_pilot_deck_template.tsv`：16 条卡片的 UTF-8 TSV 导入模板，含 Anki 可识别的字段头。建议牌组名：`英语试点::18个月路线`。
- `anki_pilot_preparation_report.md`：本次只读核查、来源、兼容性和待确认事项。

模板中的音频位置使用现有项目相对路径和时间段，例如 `assets/human/diagnostic.mp3；0–3.58 s`。没有放入 `[sound:...]` 标记，也没有复制音频；导入前需先确认是否要把文件放进 Anki 的 `collection.media`，并保留署名。

## 字段

| 字段 | 用途 |
|---|---|
| `CardID` | 人工稳定 ID，便于审阅和后续更新 |
| `阶段/日期` | 试点周次与建议日期，可改成你的实际日期 |
| `技能` | 词汇/搭配、听力理解、口语复述或写作纠错 |
| `正面提示` | 主动回忆任务；听力和口语卡先完成再翻面 |
| `背面答案` | 参考答案或评分要点；口语卡不要求逐字背诵 |
| `例句或说明` | 迁移要求、错误规则或复测动作 |
| `音频位置` | 现有许可音频和时间段；无音频卡为 `—` |
| `来源与许可` | 每条卡片的来源、许可和限制 |
| `标签` | 技能、阶段、场景、输出方式 |

1. 先确认考试类型（Academic 或 General）、每周可投入时间，以及是否接受云同步和第三方 AI 反馈。
2. 审阅每一行的答案、来源、标签和音频时间段；必要时把建议日期改为实际日期。
3. 如果要用音频，单独把已核对的文件复制到 `collection.media`，文件名保持唯一并保留 `CREDITS.txt` / JSON 中的署名；不把音频直接从网页抓取进牌组。
4. 在 Anki 导入窗口确认 UTF-8、Tab 分隔、允许 HTML、标签列为第 9 列；先导入少量测试卡并检查音频与中文显示。
5. 导入前导出或备份空白/现有配置；导入后只验证牌组和媒体，不启用同步。若不合适，删除试点牌组并恢复备份即可。
